# Security Policy

## Supported Versions

The Cherito Bitcoin Payments SDK and Gateway are currently in active development.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| 0.x.x   | :x:                |

## Reporting a Vulnerability

Security is a core principle of Cherito. If you discover a vulnerability, we would like to know about it so we can take steps to address it as quickly as possible.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them to us privately:

1. Send an email to `security@cherito.dev` with the subject `[SECURITY VULNERABILITY]`.
2. Provide a detailed description of the vulnerability, including steps to reproduce it.
3. If applicable, provide a proof-of-concept (PoC).

We will try to acknowledge receipt of your vulnerability report within 48 hours and strive to send you regular updates about our progress. If for some reason you do not receive a timely response, please reach out again.

### What to Expect
1. **Triage**: We will review the report and verify the vulnerability.
2. **Patch**: We will develop a fix for the issue.
3. **Release**: A patch will be published for all supported versions.
4. **Advisory**: Once the fix is public, we will publish a security advisory detailing the vulnerability and its mitigation, crediting the reporter if they wish.

Thank you for helping keep the Cherito ecosystem secure!
